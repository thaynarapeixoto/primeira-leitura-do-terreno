# Ficha de leitura inicial

Uma folha. As oito dimensões, com status, origem e estado de saída.

Feita para ser impressa, preenchida à mão e refeita quando o terreno mudar de hipótese. Se não couber na folha, não é primeira leitura.

**Regra de preenchimento:** campo em branco é **P**, nunca N/A. N/A exige justificativa escrita de uma linha, na hora.
